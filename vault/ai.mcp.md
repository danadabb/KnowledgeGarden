### MCP - Model Context Protocol\*\*

- open-source standard for connecting AI applications to external systems
- MCP is like a USB-C port for AI applications. It provides a standardised way to connect AI applications to external systems

### MCP Clients

- Provides a means of communication between the server and the MCP
